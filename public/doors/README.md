# Imatges per a les caselles del Calendari d'Advent (1-24)

Pots afegir aquí una imatge per a cada dia del calendari.

### Formats admesos:
Anomena els fitxers seguint un d'aquests patrons:
- `1.png` o `1.jpg` o `1.webp` (o `day-1.png`, `day-1.jpg`, `day-1.webp`)
- `2.png` o `2.jpg` ...
- ...
- `24.png` o `24.jpg` (recomanat més destacat per a la Vigília!)

### Mides recomanades:
- **Caselles quadrades estàndard**: aprox. 400x400 px
- **Caselles rectangulars amples (horitzontals, ex. dies 6, 12, 18)**: aprox. 800x400 px
- **Caselles rectangulars altes (verticals, ex. dies 3, 15)**: aprox. 400x800 px
- **Dia 24 (Gran finestra especial)**: aprox. 800x800 px

*Nota: Si per a algun dia encara no has pujat imatge, l'aplicació mostrarà automàticament un disseny nadalenc elegant amb colors festius, motius i el número daurat.*
